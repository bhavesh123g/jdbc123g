# JDBC Java Database Connectivity

It is an API.

It is used to make the Java program interact with DB.

It provides classes and interfaces which are available in the `java.sql` package.

```
+-----------+         +-------------------+         +-------------------+
|           |         |        API        |         |                   |
|   Java    | ------> |       JDBC        | ------> |        DB         |
|           |         |     java.sql      |         |  (RDBMS / SQL)    |
+-----------+         +-------------------+         +-------------------+
```
